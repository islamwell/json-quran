🛡️ Scenario B Complete Setup Instructions

Keep your main domain nq-international.com for both static HTML and media without breaking URLs:

Step 1: Create Origin DNS Record in Cloudflare

In your Cloudflare Dashboard > DNS > Records for nq-international.com:

Type Name IPv4 Address Proxy Status
A origin YOUR_PLESK_SERVER_IP DNS only (Grey Cloud) or Proxied

💡 This points origin.nq-international.com directly to your Plesk server so the Cloudflare Worker knows where to stream the MP3s and images from.

Step 2: Run the Static Converter

The converter automatically generates the static pages AND packages the Scenario B proxy files (_worker.js and _routes.json) directly into dist/:

python3 wp_static_cli.py --url https://nq-international.com --output ./dist
Step 3: Deploy dist/ to Cloudflare Pages

Upload the dist/ folder to Cloudflare Pages. Cloudflare automatically activates the _worker.js proxy for /wp-content/uploads/* while serving all HTML, CSS, and JS from the edge!

Step 4: Connect Domain nq-international.com

In your Cloudflare Pages project > Custom domains > Add nq-international.com (and www.nq-international.com). Now visits to your site hit Cloudflare Pages, and audio files stream seamlessly!

🧩 Hidden Problems in WordPress Static Conversion

Why traditional scrapers fail and how our tool specifically solves each problem:

1. 🚫 Dynamic Search (No Database)
WordPress search relies on /?s=query hitting MySQL. In a static site, this returns 404.
Our Fix: Automatically builds /search-index.json from page titles and excerpts, injecting a 3KB client-side vanilla JS search engine.
2. 📦 25MB Asset Limits for Audio/PPT
Cloudflare Pages rejects any single file over 25MB, blocking Quran MP3s and PPT slide decks.
Our Fix: Scenario B reverse proxy streams MP3, PPT, and JPG files from the origin server, bypassing all file size limits!
3. 🔗 Broken URLs & Trailing Slashes
WordPress relies on Apache .htaccess to route /about/. Static web servers need physical files.
Our Fix: Every page is stored as /slug/index.html so Cloudflare Pages resolves clean permalinks naturally.
4. 🧹 WordPress Bloat & Dynamic Heartbeat
Scripts like wp-emoji-release.min.js, heartbeat.js, and wp-embed poll dynamic endpoints.
Our Fix: Automatically strips emoji scripts, heartbeat, RSD links, and generator meta tags from HTML output.
5. 🎨 CSS Font & Background URL Paths
url(...) references in CSS files often have query strings (?ver=6.4) or broken relative paths.
Our Fix: CSS parser downloads UI fonts locally, strips version query strings, and redirects background media to origin.
6. 🛡️ Contact Forms & Submissions
Contact forms submit to admin-post.php, which requires PHP to process.
Our Fix: Point form action to serverless endpoints like Formspree, Web3Forms, or Formkeep with zero code changes.

🚀 How to Deploy to Cloudflare Pages (Step-by-Step)

Publish your static site globally in under 2 minutes:

Step 1: Run the CLI Converter

Execute the converter to generate the ./dist folder:

python3 wp_static_cli.py --url https://nq-international.com --output ./dist
Step 2: Log into Cloudflare Dashboard

Navigate to Workers & Pages > Create application > Pages tab > Upload assets.

Step 3: Drag & Drop the dist Folder

Name your project (e.g. nq-static) and drag the dist folder into the upload box. Click Deploy site.

Step 4: Connect Custom Domain

Under Custom domains, link nq-international.com and www.nq-international.com.

🔌 Optional Drop-In WordPress Plugin

If you prefer converting directly from the WordPress admin panel:

The plugin is located in wp-static-converter/ and can be uploaded to your WordPress site under /wp-content/plugins/.

  • 1. Upload wp-static-converter/ folder to wp-content/plugins/.
  • 2. Activate the plugin in WP Admin > Plugins.
  • 3. Navigate to Tools > Static Converter.
  • 4. Check "Keep heavy media hosted remotely" and click Start Static Conversion.
  • 5. Download the complete static ZIP archive ready for Cloudflare Pages!
